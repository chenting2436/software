## A — 监测覆盖与盲区

升级现有“监测覆盖分析”，不重复增加一个同义组件。

### 大屏看见什么

本地矿区地形上叠加半透明覆盖区域：蓝青表示有效覆盖，琥珀表示覆盖不足，灰色表示当前没有有效监测。传感器点、覆盖边界和两项读数“覆盖率 / 薄弱区数量”即可，不铺设备表格。

### 能做什么

1. 点设备：高亮该设备贡献的覆盖范围，右侧窄玻璃面板显示状态、电量和范围参数。
2. 点薄弱区域：放大定位，列出造成空缺的设备停用、通信中断或布设不足等原因。
3. 切换设备类型：分别看 GNSS、微震、雷达等覆盖，支持合并视图。
4. 进入布局比较：新增或移动一个候选点，左右比较覆盖变化；候选点不写入正式设备台账。
5. 保存为布设方案：保存设备集合、覆盖参数、候选点和结果截图，支持重新载入。

### 尺寸与边界

默认“标准”横向卡片；设为“主视区”后展示完整地形与候选点操作。覆盖范围先按本地参数化方法计算，不伪装为经过现场标定的实际探测距离；方法、参数和单位保留在信息入口。

## B — 故障影响链

升级现有“数据回传链路拓扑”，保留旧组件标识，避免已有方案引用失效。

### 大屏看见什么

设备 → 网关 → 接入 → 解析 → 存储 → 算法的横向图形链路。正常链路呈低亮青色，中断节点呈琥珀色，受影响的下游节点降低亮度。只保留节点短名和“受影响设备 / 任务”数量。

### 能做什么

1. 点设备或网关：突出其直接上下游，其他路径淡化。
2. 点异常：显示故障起点、最后有效数据时刻、受影响的报文与任务。
3. 切换“故障前 / 中断 / 恢复后”：用同一组设备和时间快照对比，支持回放。
4. 查看证据：从节点进入对应设备档案、数据记录或算法任务，返回后保留大屏联动状态。
5. 局部展开：只有选中路径展开，避免全项目线路全部堆在一起。

### 尺寸与边界

默认“标准”横向卡片，摘要模式只显示异常路径。设备故障只产生设备/数据链路异常，不能直接被画成“边坡风险”；算法输入中断显示“等待 / 输入不足”，不继续冒充实时运算。恢复操作仅切换本地工况，不向硬件下发指令。

## D — 三维联动剖面

新增一个独立组件。复用现有地形高程和设备位置，避免另造一套不一致的矿区。

### 大屏看见什么

三维地形中一条清晰剖切线，下方或侧方展示对应地层截面。测点、地下事件及深度标尺同时响应；不默认展示复杂参数表。

### 能做什么

1. 选择北帮、南帮、东帮预设剖面，一键换视角。
2. 拖动剖切线端点或整体平移，截面实时更新；保持地表和剖面坐标对应。
3. 切换“地层 / 测点 / 事件”图层，分别显示层间界面、传感器投影、地下事件点。
4. 点剖面中的事件：同步高亮三维空间位置，查看关联波形、设备与算法成果。
5. 时间回放：事件点随时间出现，设备状态与其他大屏组件同步。
6. 保存视角和剖面：保存端点、深度范围、图层、时间与设备选择。

### 尺寸与边界

默认适合作为“主视区”。标准卡片只显示剖面缩略图，点击展开完整操作。地形、地层、事件必须使用同一坐标系；没有真实地下模型时使用明确可追溯的本地概念地层，不把插值或概念结果当作勘探事实。
