# V2.2 三维场景与设备演示

日期：2026-09-21。客户展示名称：矿大。保留 React / TypeScript 前端和 Wails / Go 桌面封装。

## 本次交付

- 首页以三维矿区为主体，保留设备管理、数据管理、算法中心、数据回溯四个明确入口。
- 参考用户设备图，制作卫星、固定翼垂直起降无人机、四轮雷达巡检车、双太阳能翼深地感知站四个独立 WebGL 模型，并输出对应 GLB。模型支持旋转、部件点选、展开 / 收拢。
- 深地站为地表设备，地下探头作为关联采集对象；不把整台地表设备当成地下仪器。原 GNSS、微震探头、独立数采板保留。
- 新增 SAT-301、UAV-201、UGV-202、DEEP-203 四台样例设备。默认 31 台设备；旧本地数据通过追加缺失设备迁移，不覆盖用户原有档案、算法任务和大屏布局。
- 四类设备均有结构与状态、监测成果、供电与通信、任务与历史页签。支持本地模拟通信中断、恢复、操作归档，客户访客没有修改权限。
- 三维场景支持点选设备、图层开关、航迹与扫描覆盖、地下事件点云、同一工况时间轴回放。掉线设备与合成画面冻结在已记录的样例帧。
- 真实地形参照使用 Cesium 与本地公开高程，不需要登录或 API 密钥。可选的在线道路底图仅在用户开启后请求当前视野。
- 数据管理新增可点选的处理链路、遥测波形、逐设备质量矩阵；原始字段移入可展开明细，台账与原始数据功能仍在。
- 数据回溯的历史地图升级为三维场景；历史视图仍为只读，不改写当前设备工况。
- 新增 9 项可选组件，目录从 145 增至 154；原 31 算法不删减。新设备、地形、影像对比、视景与任务回放均能从组件库添加。
- 设备运行模板改为 10 个组件，包含四类设备、三维矿区和原有传感器。9 / 10 / 12 模板与多页保存预览规则保持一致，不自由拉伸、不强制覆盖既有大屏。

## 场景与素材

主场景：程序化构建的典型台阶式露天矿，含分层矿坑、运输道路、建筑、设备和覆盖区域。这是概念场景，不冒充某个真实矿区的精确数字孪生。

地理参照：白云鄂博周边公开高程，范围 109.94–110.06°E、41.755–41.845°N，来自 Mapzen / Tilezen Terrain Tiles on AWS；USGS SRTM/GMTED2010。129 × 129 采样网格，高程约 1485–1707 m。实际高程比例，不是当前矿区现场测绘。设备坐标为演示布点。

历史影像：NASA 发布的白云鄂博 2006-06-30 ASTER 图像；宾厄姆峡谷 2011-07-20 / 2013-05-02 历史影像卷帘对比。两处矿区分别标注，不伪装成同一地点的时间序列。不同传感器影像仅作可视化案例，不作为定量算法计算成果。

监控视景：用户没有提供视频，本次采用本地三维合成的无人机、车辆和地表站摄像视角，明确显示“合成视景 / 非实拍”。没有真实摄像头流，也没有将公开遥感图片说成实时视频。

完整出处及署名见 `frontend/public/scene-assets/SOURCES.md`。不需要付费账户；没有创建地图账户、申请密钥或购买服务。

## 使用方式

1. 在产品总览点击无人机或车辆标记，右侧切换“状态 / 监测”。
2. 打开设备档案，点击部件列表或模型；“拆解”展开结构，“收拢”恢复。
3. 进入“供电与通信”看电池和链路；在结构页模拟离线，再恢复，数据状态同步变化。
4. 拖动场景下方时间轴或选择任务节点，观察轨迹与样例遥测；点击播放可连续回放。
5. 切换“真实地形”查看公开高程；默认离线，只有勾选在线底图才访问外部地图。
6. 切换“历史影像”使用卷帘对比。进入“独立大屏”手动选择新增组件，或在新页面应用设备运行模板。

主概念场景和设备模型：拖动旋转，Ctrl + 滚轮缩放；普通滚轮仍可滚动页面。弹窗内部可滚动，关闭后恢复正文滚动。
