# 液态玻璃恢复 · V2.4.2

本次按用户要求撤销 MATLAB / 科学桌面风格，以本说明取代此前“独立算法窗口”的界面方向。首页、设备展厅、大屏继续使用既有视觉和交互。

## 恢复范围

- 全部主路由和子工作区统一进入深色液态玻璃外壳，不再启用 scientific appearance。
- 31 项算法回到玻璃卡片目录、图面工作区、参数抽屉和更多操作菜单。主图与两幅诊断图可切换，保留专注视图。
- SPAC 撤下标题栏、菜单栏和 Ribbon。保留现有数值引擎、通道波形、自相关曲线、台阵、拾取、拟合、项目导入与导出，以玻璃页面及弹窗呈现。
- 数据、回溯、方案、组件库、预警、账户、审计及流程编排恢复玻璃材质。回溯默认空间视图；方案和组件库恢复卡片形式。
- 计算、参数约束、归档、报告、来源说明、前端角色范围保留。解释点继续绘制在成果图上。
- 未修改大屏排版算法、点击分流逻辑或持久化结构；未清理或重置 localStorage。SPAC 使用原项目键，客户方案保留原选配键。
- 旧科学桌面组件文件保留，但不进入当前产品运行路径；生产 CSS 不再包含对应主题。
