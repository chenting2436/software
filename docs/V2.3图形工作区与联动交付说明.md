# 矿大土行孙 V2.3：图形工作区与业务联动

日期：2026-09-21。沿用 React / TypeScript、Three.js、Cesium 和 Wails / Go，不更换技术栈，不覆盖已有用户大屏方案。

## 本轮完成

1. 四大主模块继续保留：设备管理、数据管理、算法中心、数据回溯。独立大屏、预警闭环和系统管理放在次级分组。
2. 设备档案与算法详情采用独立地址。跳转携带设备、数据批次、任务版本或回放时间；支持浏览器返回。设备筛选、算法目录筛选和数据中心当前页签保留在会话中。
3. 算法目录改成 31 张成果缩略图；每个算法提供 1 幅主成果、2 幅诊断图。参数与原始字段默认收起，主次图可互换。
4. 增加多道波形、频率—波数谱、相速度能量、慢度扫描、三分量频谱、H/V 窗口集合、机制球、赤平投影、地层/裂缝/事件三维结构、风险证据关系等表达。
5. 三维成果支持旋转、Ctrl + 滚轮缩放、点选、深度筛选、地层/事件/结构图层开关；普通滚轮保留页面滚动。切换图层时保留相机位置。
6. 本地处理通过 Web Worker 执行。修改输入后必须重新计算才能归档；参数错误保留上次成果，不生成伪造完成进度。
7. 新归档同时冻结输入、排除通道、解释点、方法、成果指纹和图面数值。版本比较及证据回溯引用对应记录；旧版未存图面的任务显示为兼容引擎重建。
8. 数据中心增加输入/标定结果曲线、回传连续性、处理链路。进入报文/解析页时保持当前设备，不再跳到默认设备。
9. 已归档成果可人工登记研判，并进入确认、派发、反馈、复核、关闭流程。独立分析必须明确选择关联对象，不自动套用当前选中设备。
10. 闭环页面和报告使用关联算法成果，不再统一填入一条无关的位移曲线。报告从成果数据生成，与当前打开的页签无关。
11. 算法报告导出为可打印 HTML，支持打印为 PDF；另可导出结构化 JSON 和证据包。三维报告包含二维空间索引图，完整三维交互仍在工作站内查看。
12. 大屏算法卡片优先展示已有归档成果，点开进入同一版本。设备、数据、风险卡片可进入具体对象。154 个组件和 9 / 10 / 12 模板继续保留；模块按预设规格排版，不能自由缩放，同屏不重复添加。

## 31 项算法的实际实现边界

所有项目均有专属的三视图组合、成果查看、版本归档、对比和导出入口。“有工作区”不等于已实现生产级求解器。

### 12 项本地校验处理

| 入口 | 本轮实际执行的处理 |
| --- | --- |
| 主动源炮集 | 合成道集整理、坏道排除、测线/炮点索引 |
| τ-p | 时域线性移位叠加与慢度扫描 |
| f-k | 时间 FFT 与空间离散傅里叶扫描 |
| 相移法 | 归一化频谱相移扫描与逐频峰值 |
| 倾斜叠加 | 截窗、时移及有限道数叠加 |
| 频散拾取 | 逐频能量最大值与门槛筛选，不是完整多阶自动跟踪 |
| MAPS | 双台时域互相关与等权叠加校验，不是完整工程 MAPS 流程 |
| Beamforming | 十二站合成平面波的窄带延时求和 |
| H/V | 合成三分量 FFT、谱比及有效窗口统计 |
| 事件识别 | STA/LTA、触发门槛及候选窗口 |
| P/S 初至 | 能量触发候选与人工解释入口，尚不自动区分可靠的 P/S 到时 |
| GNSS 趋势 | 最小二乘线性外推与残差带；非经过校准的概率预测 |

这些处理使用确定性的合成校验输入；未接收现场设备流。每个入口只开放本轮参与处理的参数。数据长度、采样率与扫描范围有限，不可据此宣称达到原需求书中的速度、精度或稳定性指标。

### 19 项参考成果审阅

高分辨率拉东、主动源联合反演、测线成像、SPAC、ReMi、F-H、CMP-TS、被动源联合反演、观测系统设计、速度模型、微震定位、震级能量、矩张量、应力反演、裂缝网络、渗透率/SRV、事件属性、边坡稳定性、多源风险。

以上展示固定参考模型和合成场景。切片、图层及解释操作改变显示与审阅状态，不执行相应的工程反演或安全评估求解器。没有填写虚假的算法精度、成功率、开发人日或实时计算能力。

## 推荐展示路线

1. 项目总览：查看三维场景、设备状态与监测视景。
2. 从测点进入数字档案，再打开关联采集数据；观察对象编号连续保持。
3. 进入算法中心：先展示频散能量图，再切换 H/V、裂缝网络或机制球。
4. 修改输入或排除窗口，重新处理、保存成果；使用版本对比和输入追溯。
5. 从已保存成果转入研判，填写依据，完成闭环处置并导出报告。
6. 最后打开独立大屏，展示组件选配、自动拼版和同版本成果钻取。

## 数据与存储

- 页面标题、导航和操作采用产品语言；来源集中放在项目页脚、来源面板、成果记录和导出文件中。没有把合成视景标成现场实拍。
- 旧浏览器数据使用原存储键继续读取；新旧 EXE 仍沿用原程序文件名，避免无必要更换应用标识。
- 大屏方案与业务记录分别保存。浏览器开发端、生产预览端和 EXE 的存储彼此独立，不能认为已自动同步。
- 图面只在主成果记录存一份，操作快照不重复复制大型数组。本地存储接近上限时阻止继续归档并提示导出；不是无限容量的生产数据库。
- 前端角色切换是已约定的展示权限效果，不是服务端鉴权。
