# 大屏点击交互修复 · V2.4.1

## 原因

摘要化改造后，一部分卡片只在右上角展开按钮绑定了操作；图形、数字、账号头像仍是静态内容。地图摘要中的测点也没有带入所选设备编号。

## 本轮修复

- 31 项算法与算法别名摘要提供覆盖图面、可用键盘激活的原生按钮。已有成果携带任务与输入设备上下文进入分析页面。
- 设备环图、状态数字打开当前状态列表；设备类型图标打开该类型全部设备；列表进入所选设备档案。
- 地图设备点及平台模型直接打开对应设备；地图/模型拖动不触发卡片跳转。
- 回传图、当前值和回传状态条进入对应设备数据。数据质量环图按入库、隔离、中断筛选。
- 预警点进入对应风险事件；普通测点进入设备。待处置数字打开未闭环事件列表。
- 闭环阶段条按实际当前阶段计数和筛选，不再将累计人数展示为当前阶段数量。零记录也提供明确空状态。
- 账号头像、角色条打开只读资料；未增加账号修改权限。
- 算法任务状态打开对应任务列表；历史时刻和快照入口保留精确时间、快照编号。
- 卡片标题和无控件区域提供工作区入口。子按钮、抽屉门户、三维画布有独立事件边界，避免重复跳转。
- 保留当前视觉、组件数量、排版、保存格式和角色数据范围，不修改用户 5174 来源中的布局或业务记录。
