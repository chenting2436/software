## 使用

账号 `root`，密码 `root`。这是本地前端登录，不是服务器认证。

桌面程序内置前端资源，不依赖 Node、Go 或 5174 开发服务。运行环境为 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime；缺少 WebView2 时，安装包会调用微软引导程序安装，此步骤需要联网。

本机网页已恢复为 `http://127.0.0.1:5174/`，仅监听本机回环地址。开发服务不是开机自启动服务，电脑重启后需重新启动；桌面程序不受影响。
