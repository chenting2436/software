# 矿大土行孙 V2 · 本次网站改造交付

> 历史版本说明：本文件对应第一轮改造。最新交付请看《V2.1产品改造交付说明.md》；固定 3×3/最多 9 项及 138 组件的描述已被后续版本替代。

## 运行入口

- 网站开发预览：`http://127.0.0.1:5174/`。5173 属于另外一个项目，本次未修改。
- 桌面程序：`build/bin/Kuangda-Tuxingsun-V2-Demo.exe`。
- 安装包：`build/bin/矿大土行孙V2演示系统-amd64-installer.exe`。
- EXE 内嵌前端资源，无需启动 Vite 或联网。运行环境需要 Windows x64 和 WebView2。
- 浏览器与 EXE 的本地数据相互独立，未接入真实设备、认证或远程服务。

## 界面与组件

新版主入口为 `frontend/src/studio/StudioApp.tsx`，沿用用户已有的大屏布局，不强制覆盖。

1. 重建侧栏、首页、设备、数据、算法、预警、方案、组件库和配置入口，使用矿大蓝灰配色。
2. 138 个组件均可从排版组件库选择。每屏固定 3 × 3，最多 9 项，同种组件只出现一次。可移动、交换、移除、重新添加，保存与预览共用坐标。
3. 提供综合监测、算法成果、设备运维三个九宫格模板。应用模板后需要保存。
4. 首页支持离线平面地图、地质分层爆炸图、设备结构拆解三种视图。模型是代码生成的三维投影示意，支持拖动旋转、缩放、分层展开和点选；不是实测地形或精密设备 CAD。
5. 平面地图包含监测区、等高线、台阶道路、设备、风险示意范围和点位联动。
6. 九宫格为摘要视图，进入工作区后提供完整业务表单和记录，避免把长页面压缩到卡片内。

## 可操作业务链

- 设备：查询、区域/状态筛选、分页、档案新增编辑、JSON 模板导入、CSV 导出、掉线/恢复/维护状态，设备详情与地图联动。
- 数据：协议与报文筛选、原始报文、字段映射、标准值、处理日志、标定重处理、回放及导出；设备掉线会令对应报文中断。
- 算法：31 项独立参数规范、输入说明、步骤和成果指标。共享工作台支持通道筛选、图面解释、参数响应、运行进度、失败/取消/重跑、任务快照与版本载入、成果导出。
- 预警：多源融合算法可生成关联任务的候选风险；确认、派发、反馈、复核、关闭必须填写说明；保留责任人和时间线，生成包含证据与处置记录的 HTML 报告。
- 账号：前端角色切换、按钮操作限制、客户访客北帮范围、账号配置与启停样例。账号列表配置不等同于实际登录系统。
- 方案：138 项能力勾选、依赖提示、工作包说明、JSON 配置与 HTML 客户方案。没有编造人日或报价承诺。
- 配置及补充业务：使用按功能定义的字段、记录、操作回执、版本与复核工作台。协议自测可解析标准样例 JSON。其他运维行为是本地流程模拟，未执行真实远控、灰度、服务重启或消息发送。

## 重要边界

本次是可交互演示，不是 31 个工程算法的生产实现。图表与结果是可复现的样例响应，不执行真实反演、定位、稳定性求解；不得用于矿山安全判断。部分辅助模块复用配置/记录工作台，而非逐项实现原始需求书中的生产级基础设施。

HTML 报告可在浏览器打开并打印为 PDF；本次未提供原生 Word/PDF 报告生成器。桌面导出使用系统保存窗口。内置浏览器的下载事件在自动化检查中未捕获到，因此未把网站文件落盘标记为已验收；建议交付演示优先使用 EXE 的原生保存。

演示场景切换会重新装载场景设备/事件样例。正常业务编辑保存于当前运行环境本地存储，不是跨端共享数据库。
