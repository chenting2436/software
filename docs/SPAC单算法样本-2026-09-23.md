# SPAC 单算法界面样本

状态：已实现并获用户认可。本文件记录 SPAC 样本交付时的范围；后续算法扩展见《算法独立窗口改造-2026-09-23.md》。

入口：http://127.0.0.1:5174/#/algorithm/spac

## 外观与范围

- 独立桌面软件式窗口：标题、菜单、彩色分组工具栏、文档标签、大绘图区、结果标签、底部坐标状态栏。
- 不显示网站导航、左侧系统栏、指标卡及介绍性大标题。
- 波形、自相关、台阵、频散能量、拾取结果在同一窗口切换。
- CSS 全部限定在 `spac-` 命名空间；新增入口只拦截无历史任务参数的 SPAC 路由。
- 首页、设备、大屏和其他算法本轮没有重设计；前一轮中途停止的全站改动未回滚，也未继续扩展。
- 旧 SPAC 任务的 `task` 深链接继续使用原有归档工作区。

## 已实现的样本交互

- 两组内置合成数据，通道数、距离组、波形和相关系数不同。
- 频率、速度、速度步长、窗口及平滑参数校验；修改后仍显示旧图，并显式提示待计算。
- 独立 Worker 运行匹配扫描，按真实计算进度反馈，可停止；异常和停止保留旧结果。
- 波形去趋势、归一化；图面配色、网格、十字线、频率轴缩放和平移。
- 点击或数值拾取、删除、撤销、二次拟合、拾取表格及波长/匹配度读取。
- 有拾取点时重算须确认；保存配置和拾取点使用独立本地键 `kuangda-spac-workbench-v1`，不覆盖设备、大屏或算法归档数据。
- SVG 图面、CSV 拾取、JSON 项目导出；仅支持本工具的 JSON 项目导入，有大小和参数/坐标范围校验。
- 遵循现有算法角色权限；原始文件不包含可执行内容。

## 数值和数据边界

参考关系为 ρ(f,r) = J₀(2πfr/c)，见 [Geopsy 的 SPAC 说明](https://geopsy.org/wiki/index.php/Ambient_vibration_array)。本样本将合成环组自相关系数与 J₀ 模型匹配，显示归一化匹配度。不是完整的现场 SPAC 数据处理系统，也没有调用参考压缩包中的 EXE。

波形是配套合成预览，不是相关系数的采集来源；统计窗口控制合成系数扰动水平。拟合是对数频率域的二次最小二乘拟合，不是地层反演。以上边界可在界面“帮助”中查阅。SEG-Y、MiniSEED 和真实设备接入不在此次样本范围。
