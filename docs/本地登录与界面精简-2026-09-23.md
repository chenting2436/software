# 本地登录与界面精简

## 本轮范围

- 入口增加本地前端登录：账号 `root`，密码 `root`。同一标签页刷新保持会话，退出后重新登录；所有页面路由（包括大屏和编排）均先经过登录页。
- 登录状态只写入 sessionStorage，不保存密码；退出只删除会话，不删除设备、任务、大屏等本地业务配置。这是本地界面入口，不是服务端鉴权。
- 顶部用户入口改为当前账号、账号管理、退出登录；角色预览仍在账号管理页。问号入口仅显示版本号 V2.4.2。
- 移除设备、数据、算法、回溯页面的重复栏目标题。大屏编排使用独立布局，不再叠加全站导航；有明确的返回入口。
- 数据子导航、处理阶段和功能库按钮紧凑化。六个处理阶段分别展示采集曲线、回传链路、字段映射、质量连续性、存储索引和关联算法任务。设备列表支持搜索并定位当前选中项。
- 算法主界面移除参考版本、成果数量、审阅模式和说明性段落；物理单位、异常警告和操作能力保留。来源、方法及原始成果属性仍可在“更多 → 数据与方法”及导出中查看，不改写保存的成果。
- 电源卡片改为左侧设备图标/编号、右侧供电数值/状态；移除“后备电量”等重复标签。
- 自建地形高程使用深蓝、青色、绿色、金色、浅色五级渐变，保留高程图例和单位。
- 工作区弹窗按上下文去重标题，简化回溯与报文界面的说明文案。

## 验证

- `frontend` 下执行 `node --test tests/*.test.mjs`：108 项通过，0 项失败。
- `frontend` 下执行 `npm run build`：通过。保留既有的大包体积警告；测试打包器有既有的 CJS/import.meta 警告，生产构建使用 Vite 模块格式。
- 浏览器检查尺寸：1280×720、1440×900、1920×1080。
- 1280×720：数据采集、功能目录与编排页无文档横向溢出；29 个数据功能按钮均未截断；专业图面工具未遮挡图表内容。
- 本地隔离测试来源 `localhost:5174`：调整一项组件顺序后保存，9 项组件的 kind/rect 在编排、预览、刷新后完全一致；退出、重新登录后仍一致。
- 大屏设备台账入口能打开弹窗，标题只出现一次。
- 登录错误、正常登录、刷新保持登录、退出后刷新仍须登录均验证通过；版本入口仅显示版本。
- 测试标签页控制台未发现 error。

## 交付边界

本轮更新网站源码和前端生产资源，未重新打包 Windows EXE/安装器。保留原业务数据、原算法计算/审阅边界及来源信息，没有接入真实设备或服务器认证。
