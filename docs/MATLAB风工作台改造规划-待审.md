# MATLAB 风工作台改造规划（待用户审查，尚未实施）

## 参考依据

已读取用户提供的“被动源面波数据处理软件_免安装版.zip”的说明及 EXE 中内置的 HTML 界面，并在临时本地浏览器中查看主绘图区、工具栏和参数窗口；未运行该 EXE。

参考特征：浅蓝灰菜单与分组工具栏、白底绘图区、明确的坐标与单位、方法选择、独立参数窗口、文档标签、底部结果标签与状态栏。借鉴操作组织与科学绘图语言，不复制对方名称、Logo 或假窗口按钮。参考包本身声明为模拟界面，不是可直接接入的地震算法引擎。

## 方向与边界

采用“展示界面 + 科研工作台”两种界面体系，共用项目、数据、任务和角色状态。

- 设备管理整条路径保留：设备展厅、三维模型、爆炸图、设备档案、台账、供电通信与诊断。
- 大屏预览与编排保留：深色配色、毛玻璃、组件规格、自动补位、已保存布局、点击详情。
- 算法、数据、回溯重构为科研工作台，不仅换背景色。
- 预警、流程、方案、账号、配置、组件目录统一为浅色工具软件风格，但按各自业务采用图面、列表、表单或文档，不硬套频散图布局。
- 首页为一项待确认建议：用户此前明确喜欢现有首页，建议连同设备、大屏保留现有三维视觉。如用户坚持“除设备和大屏之外全部改”，首页改为浅色工作台外框，仍保留矿区场景和设备点选，不新增宣传文案。
- 新工作台使用浅灰实体工具按钮、清楚的选中和禁用态；不继承此前全站毛玻璃要求。设备和大屏的毛玻璃保留。

## 工作台结构

固定产品导航：总览、设备、数据、算法、回溯；预警、方案、系统工具收纳到相应菜单。

页面内部：上下文菜单/分组工具栏 → 数据或任务标签 → 主工作区 → 结果标签 → 状态栏。主图优先，项目树和参数面板可折叠。默认一张主图，支持双图对比，不默认铺满许多小卡片。控制文字采用短名，单位和必要专业字段保留，说明移入提示或帮助。

建议绘图区为白色、面板浅灰蓝、细分隔线、2–4 px 小圆角、12–14 px 控件文字；取消大渐变卡片、宣传标题和装饰性大数字。沿用矿大品牌蓝，不照搬旧 Windows 窗口装饰。

## 算法工作台

现有 31 项算法全部保留，按以下六类图面模板组织，而非共用一种图：

1. 波形与事件处理：多道波形、三分量、时窗框选、坏道标记、到时标记、处理前后对比。
2. 频散与波数分析：二维能量图为默认，保留三维能量面切换；曲线阶次、拾取、撤销、色标范围；不同方法显示自己的坐标量纲。
3. 频谱与 H/V：分量谱、谱比、窗口集合与主峰；阵列/波束采用台站布设和方位慢度图。
4. 反演与剖面：观测/拟合对比、Vs–深度模型、残差、模型集合、剖面与切片。
5. 微震与地下结构：三维事件/射线/裂缝、二维投影、机制球、应力方向；坐标、尺度、色标与联动选择清楚。
6. GNSS 与风险：观测/预测分界、预测区间、残差、证据关联与边坡剖面，不改成普通统计仪表盘。

统一工具：视图复位、放大/缩小、适用图面的平移或框选、数据光标、图层、图像/数据导出。拾取/排除/切片/版本对比等按方法适配；不提供无响应的统一假按钮。

操作路径：选数据 → 选方法 → 改参数 → 运行或载入成果 → 图上解释 → 归档/导出。修改参数必须标记待运行，旧成果不伪装成新计算结果；已有归档不可被工作副本覆盖。

## 数据工作台

保留采集、回传、解析、质检、存储、算法输入六段流程，但缩为处理链/上下文标签，不再占用六张大卡片。

左侧按项目、设备、批次、通道浏览；中央默认波形或趋势；预处理对比、缺失段、异常点、时间同步/延迟按对象展示。原始报文、字段映射和精确数值作为下方标签，不在第一屏铺满 JSON。

工具按上下文提供时间范围、通道、筛选、重处理、映射、批次创建、送入算法、导出；默认不展示无关操作。选择设备数据再进入算法时保持批次、设备、时间段和兼容方法，不回到无关示例输入。

参考软件列出的 SEG-Y/SAC 等格式不自动等于本产品支持。实际文件解析能力属于独立开发范围，只显示已有实现或经本轮确认新增的格式。

## 其余模块

- 回溯：同一时间游标驱动历史曲线、事件标记、地图和快照；版本对比左右联动；来源与参数按需展开。
- 预警：左侧事件索引，中央证据图，右侧处置；确认、派发、复核等为紧凑操作，保留流程与权限。
- 流程编排：浅色网格画布、节点工具箱、节点参数属性栏；保留连接与配置。
- 客户方案/报告：左侧功能树，中央分页文档预览，右侧配置/目录；功能勾选联动方案，保留导出。
- 账号/配置/审计：浅色工具栏、必要数据表和属性表单；保留角色矩阵、状态与审计，不强行改成图表。
- 功能目录：154 项组件保留，分类树与紧凑检索取代宣传卡片；完整工作台为浅色，大屏内摘要仍为深色。

## 保留的技术与数据

保留现有前端、Go/Wails 包装、计算与归档逻辑、角色范围、设备模型、地图、组件 ID 和布局存储。科学图支持工作台/大屏两套外观，不全局覆盖颜色。弹窗主题跟随来源页面，避免样式串到设备或大屏。
