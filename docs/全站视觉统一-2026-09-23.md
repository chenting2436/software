# 全站视觉统一 · 2026-09-23

本轮将首页与无人机样板的深蓝展厅语言扩展到整个网页工作站。保留原业务数据、权限矩阵、154 项组件及大屏存储格式，不更新安装包。

## 交付变化

- 所有非大屏预览路由使用相同顶部导航。工作台保留大屏编排、预警、组件、方案、流程、账号与配置入口；增加可收起搜索和统一来源说明。
- HTML 按钮、页签、菜单与弹窗使用半透明渐变、背景模糊、细高光；成果图与模型不施加模糊。
- 设备总览由多模型卡片墙改为单模型展厅，支持空、天、地、深、GNSS、微震、独立数采板七类切换；台账、通道、协议、诊断、维护仍可访问。
- 四类平台设备统一全幅设备详情，保留部件选择、拆解、环绕、遥测、影像/巡检视景、关联采集数据、回溯与完整工作区。
- 传感器主图仅标注当前部件，其余部件可通过左侧按钮或模型选取；详细解释及供电协议按需展开。
- 全部 31 个算法工作区统一图面优先结构：参数、运行、归档为常用动作；版本、输入、导出、追溯及来源在“更多”中。三幅成果与解释点保留。
- 数据管理压缩链路文字；历史报文、组件能力说明、方案范围与排版规则改为可展开信息。
- 大屏与内部地图采用首页同款概念地形，控件与其余工作站统一；保存和预览继续共用拼版坐标。
- 修正从组件进入设备台账时，被总览记忆页签覆盖的问题。

## 验证

- `npm run build` 通过。Vite 仍提示 Three/Cesium 相关大体积 bundle，不影响当前构建；未在本轮调整依赖分包。
- `node --test tests/*.test.mjs`：55 项通过。包括 154 项组件渲染、31 算法图面、角色限制、历史冻结、保存布局、全站路由与新增样式回归。
- 在独立 4174 测试源实际验证：相速度 180–700 m/s 参数运行与图面更新；归档后输入追溯；卫星历史影像弹窗关闭恢复滚动；方案范围展开不改变勾选；九组件保存和预览逐项坐标一致。
- 浏览器巡查覆盖数据、回溯、风险、账号、配置、目录、方案、流程、编辑器、预览及代表性组件工作区；修正残留白色面板。实际检查窗口包含 1280×720 与 1038×990，后者大屏没有页面横向溢出。
- 业务写入测试仅在独立 4174 源进行，未重置 5174 用户项目数据。

## 边界

本轮为网页视觉与交互改造。算法计算能力不因视觉调整而扩大：12 类本地计算、19 类固定参考成果的现有边界不变；数据和场景来源继续可查。没有真实设备接入、生产身份认证或新安装包。
