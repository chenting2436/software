# 液态玻璃完整工作区

## 本轮已实现

- 31 项算法都有图形优先的详情入口。保留相移、震源定位、边坡三个空间样板，其余使用接收波场、扫描能量、环形台阵、地层切片、事件群、震源机制、裂缝、位移外推、风险证据等展示形式。
- 目录卡片仅保留序号、名称和图示；1280 宽四列，640 宽两列，大窗口继续增列。大屏算法摘要也改为同系列空间图示，已有归档时显示一项实际归档指标。
- 专业分析、参数、运行或参考成果载入、标记、版本、归档及导出保留。SPAC 增加环组/频率总览，原拾取工作区从专业入口打开。
- 统一居中液态玻璃弹窗，包括参数、设备详情、组件展开、SPAC 配置和巡检画面。支持嵌套弹窗、Escape、焦点圈定、背景禁用与滚动恢复。
- 巡检画面直接填满 16:9 容器，隐藏载机自身和地图标记。透明左上角保留名称/模拟标识、时刻、高度和速度，不再重复显示长说明。
- 本地地形加强山谷、矿区台阶、分级道路、服务道路、植被和不规则水面。首页、大屏、回放及巡检共用同一高度场；在线地理参照保持独立入口。
- 设备页面简化标题与通道控件；历史与证据独立为紧凑图表面板，不再嵌入整个回溯工作台。孤立归档快照不冒充连续历史曲线。
- 原始结构化记录改为简明字段摘要及下载，不直接展示 JSON 块。
- 大屏编排和预览共用固定比例设计画布；1–12 项自动填满预设槽位，支持 9/10/12 模板、16:9/21:9、每屏单组件唯一、拖动交换、前后移动、主视区、撤销/重做、最近 8 个保存版本恢复及设备/时间上下文。
- 编辑态内部交互隔离，防止拖拽误跳转；预览态点选和展开恢复正常，展开后可进入完整工作区。

## 验证

- TypeScript 与前端生产构建通过，96 项自动测试通过。
- Go 包编译检查通过；这两个 Go 包本身没有测试文件。
- 浏览器验证：1280×720 设备历史主要内容完整可见；巡检容器与 canvas 尺寸吻合，无原有下部空洞和载机遮挡。
- 1920×1080 九组件大屏无水平溢出；编排与预览逐项 data-rect 一致。
- 十二组件 21:9 模板同样逐项一致，重复组件添加按钮禁用。
- 验证了移动/撤销、保存/预览、组件展开、嵌套弹窗关闭与 root inert 恢复、SPAC 参数和专业拾取入口。
- 640 宽目录双列，无水平溢出；临时视口设置已恢复。
- 测试写入限定在 localhost:5174，未清空或覆盖用户 127.0.0.1:5174 的大屏、任务、快照。

## 边界与待交付项

- 本轮是网页实现，旧 EXE 与 2.4.2 安装包未重打包，不应当作本轮前端版本。
- 当前依旧没有接入真实设备、摄像头或现场测绘。巡检为实时渲染的模拟视景，不是真实视频流。
- 算法视觉覆盖不等于所有算法均为生产求解器：已有本地计算方法保留真实的本地计算链，其余成果明确保持参考模式。结构图、参考事件和裂缝用于功能表达，不虚构现场精度或工程安全结论。
- 原有归档和用户配置不迁移、不清空。构建仍有现有大包体提示，后续可另做分包优化。
