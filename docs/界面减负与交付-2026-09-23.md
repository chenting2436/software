# 界面减负与 V2.4 交付

本轮按已批准的界面规划实现，保留业务功能、31 项算法、154 项组件及原有本地数据。不重置用户大屏，不改接真实设备或后端鉴权。

## 已落地

- 导航固定五个业务入口：总览、设备、数据、算法、回溯；大屏、搜索、账号及更多工具分离。选中态保留毛玻璃，数据行与次级列表减弱边框。
- 首页移除宣传标题和重复说明，以矿区场景、状态和设备选择为主；设备编号按选中或悬停显示。
- 大屏取消重复类别、描述及“进入工作区”页脚。每个组件为标题、图形摘要、单一展开入口。设备、回传、风险位置、闭环进度、账号、历史分别使用对应摘要。全部组件仍可手动添加，单屏不重复，固定预设尺寸及自动补位保持不变。
- “已迁移监测屏”“原布局组件”仅在展示层映射为简短名称，不写回覆盖存储。编辑、保存、预览继续使用同一坐标函数。
- 算法保留一个主图和两个可展开诊断图；参数及数据来源改为侧栏，保留计算、通道选择、标记、归档、版本、导出、输入追溯。
- 设备保留模型、部件点选和拆解；部件说明与诊断按需展开。数据保留六节点流程和信号，节点详情按需展开。回溯优先地图与时间轴，报文和成果归档按需展开。
- 账号编辑、权限矩阵、配置记录详情和编辑统一为侧栏。侧栏包含背景隔离、键盘焦点约束、Escape 关闭、关闭后焦点与滚动恢复。
- 台账筛选在返回后保留；快照链接带入对应快照和时间，普通非三维设备也可直接打开档案。
