## 本轮变化

1. 三个样板采用顶部核心导航、深蓝黑背景和大画面构图，原侧栏工作区仍可通过核心导航、工作台菜单及完整工作区入口到达。
2. 首屏以本地三维矿区为主，包含设备选中状态、空天地深设备入口、地下图层、区域地形入口和工况回放。设备状态从现有项目状态读取，不是写死的在线数量。
3. 无人机详情提供环境光材质、投影、外观细节、部件点选与爆炸展开。点击电池或飞控可切换状态读数。巡检视景弹窗支持 Escape 关闭并恢复页面滚动。
4. 频散分析增加三维能量面 / 二维图面切换。三维高度和点选读数来自同一计算矩阵；参数变化后重新计算，物理坐标范围同步改变。保留原有归档、对比、报告和证据回溯。
5. 保留原大屏保存方案、154 个组件和混合尺寸拼版规则；未修改存储键，也未升级或覆盖 EXE 安装包。
